# 04-setup-deployment (설정 & 배포)

환경 설정, 배포, LLM 서버 구성에 관한 문서

## 📑 폴더 구조

### 루트 파일들
- **STACK_VERSIONS.md** — 사용 중인 라이브러리/도구 버전
- **CONFIG_MULTI_LOGIN_ANALYSIS.md** — 다중 로그인 설정 분석
- **CONFIG_STORAGE_ANALYSIS.md** — 저장소 설정 분석

### llm-server/ — LLM 서버 설정
- **LLAMA_CPP_SERVER_SPEC.md** — Llama.cpp 서버 스펙

---

## 🎯 읽기 순서

1. **STACK_VERSIONS.md** — 현재 스택 확인
2. **CONFIG_MULTI_LOGIN_ANALYSIS.md** — 로그인 설정 이해
3. **CONFIG_STORAGE_ANALYSIS.md** — 데이터 저장 방식 이해
4. **llm-server/LLAMA_CPP_SERVER_SPEC.md** — 로컬 LLM 구성 (필요시)

---

## 💡 빠른 설정 가이드

1. Node.js 버전 확인: `STACK_VERSIONS.md`
2. 로그인 설정: `CONFIG_MULTI_LOGIN_ANALYSIS.md`
3. 데이터 저장소 설정: `CONFIG_STORAGE_ANALYSIS.md`
4. 로컬 LLM 사용: `llm-server/LLAMA_CPP_SERVER_SPEC.md`
